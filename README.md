# Додзё — приложение для тренера по карате (Android)

## Как получить APK без установки Android Studio (≈10 минут)
1. Зарегистрируйтесь на github.com (бесплатно).
2. Создайте новый репозиторий (кнопка New) и загрузите в него ВСЕ файлы из этой папки
   (Add file → Upload files). Важно: папка `.github` тоже должна загрузиться.
3. Откройте вкладку **Actions** → «Build APK» → **Run workflow**.
4. Через 5–8 минут откройте завершённую сборку и скачайте файл **dojo-apk** (внутри app-debug.apk).
5. Перенесите APK на телефон, откройте его и разрешите установку из неизвестных источников.

## Как поменять приложение
Вся программа лежит в `www/index.html`. После правки загрузите файл в репозиторий — APK соберётся заново.

## Важно
- Данные хранятся в самом приложении на телефоне. Делайте «Резервную копию» в разделе «Ученики».
- При удалении приложения данные пропадут.
